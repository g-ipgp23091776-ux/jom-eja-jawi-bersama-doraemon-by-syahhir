Tetapan Pautan Google Sheet

Masukkan URL Google Apps Script Web App untuk menghantar rekod markah murid secara automatik ke Google Sheet guru.

💡 Cara Menguruskan Google Sheet (Ringkas):

  1. Buka Google Sheet baharu.
  2. Klik Extensions > Apps Script.
  3. Tampal kod Apps Script di bawah dan klik Deploy > New Deployment (Akses: Anyone).
  4. Salin URL Web App dan tampal di kotak di atas.
